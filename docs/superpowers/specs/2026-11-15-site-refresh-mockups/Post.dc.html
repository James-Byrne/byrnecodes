Ember and tailwindcss

Have you heard how awesome tailwindcss and Ember are together!?

Using tailwindcss

For the last year or more, both in work and at home, I’ve been using tailwindcss for styling. I love composing styles together with CSS utility classes to create great user interfaces and experiences. Overall I’ve found it great, and its functional, compositional nature really gels with me.

I also love its component system. Reducing the number of abstractions to be made up front is a godsend for any project growing quickly.

Since I like it so much, and I use it in pretty much all the examples in my posts, I thought I’d write up a quick guide for getting running with tailwindcss and Ember.

Cool! … but what is it though?

For those of you that haven’t worked with it yet, tailwindcss is a utility-first framework. You start with a set of CSS classes, each of which does one thing well, then compose them to get more complex behaviour. For example, below is a simple, overly excited, button.

<button class="bg-pink-500 text-white">Press ME!</button>

The classes are pretty self-explanatory, but let’s go through them anyway:

  • bg-pink-500 sets the background colour
  • text-white sets the text colour
